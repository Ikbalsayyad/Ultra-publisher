LOGIC BUILDER

Let's understand the logic behind our Smart Climate Monitor.

FLOW OF LOGIC

Start
Read Temp from DHT11
Read Humi from DHT11
Store Variables (t, h)
Display values on OLED
Wait 2 Seconds
Repeat Forever

PYTHON LOGIC PREVIEW

PYTHON LOGICmain.py
import dht, time
from machine import Pin, I2C
from ssd1306 import SSD1306_I2C

sensor = dht.DHT11(Pin(4))
i2c = I2C(1, sda=Pin(21), scl=Pin(22))
oled = SSD1306_I2C(128, 64, i2c)

while True:
    sensor.measure()
    t, h = sensor.temperature(), sensor.humidity()
    oled.fill(0)
    oled.text(f"Temp: {t}C", 0, 10)
    oled.text(f"Humi: {h}%", 0, 30)
    oled.show()
    time.sleep(2)
