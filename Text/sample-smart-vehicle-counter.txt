🧬 Nova’s Concept Lab: Edge Detection & Debouncing
"Did you know, young coders, that computers think millions of times faster than a car can drive? When a toy car rolls past an infrared sensor, its body takes about 1 whole second to pass. But our UltraBoard reads the sensor 1,000 times every second! If your code simply says 'If sensor detects car, add 1', the computer will add 1,000 to your counter for just one car! In engineering, solving this is called Edge Detection or Debouncing. The code must count 1 the moment the front bumper arrives, and then wait patiently until the rear bumper has completely cleared the beam before counting again!"

📄 PHASE 4: CODE STUDIO AT ULTRA STUDIO
"Laptops open! Head to code.ultramindsai.com and open Ultra Studio!"
💻 The Block Code Script:
codeText
set [car_count] to [0]
repeat while <true> do
    set [car_sensor] to (Sensor # (0-99) [1])
    if <(car_sensor) > 40> do
        set [car_count] to <(car_count) + 1>
        Play Tone Output # [1] Hz: [1200] Sec: [1]
        Flash LED Output # [2] Pattern: [Normal Blink] Times: [1]
        repeat while <(Sensor # (0-99) [1]) > 40> do
            wait (0.1) Sec
________________________________________
🎛️ Nova’s 3-Step Coding Guide:
1.	Initialize the Counter Variable: Under Variables, create car_count. Above the loop, snap: set [car_count] to [0].
2.	Detect the Front Bumper: Inside repeat while <true>, measure car_sensor. If car_sensor > 40, snap:
set [car_count] to <(car_count) + 1> (found under Math)!
3.	Play Chime & Debounce: Snap Play Tone Output # [1] Hz: 1200 from Adv. Robotics. Then add:
repeat while <(Sensor # 1) > 40> do wait (0.1) Sec to hold until the car has driven completely past!
