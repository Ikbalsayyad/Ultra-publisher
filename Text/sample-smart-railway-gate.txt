📄2: THE ENGINEER’S TOOLBOX
Here are the modular plug-and-play electronics blocks we will use. No coding required—they snap together directly!
codeCode
[ 🔋 POWER + SWITCH ] ➔ [ 👁️ SENSOR BASE ] ➔ [ ⏱️ TIMER ] ➔ [ 🔀 COPY ] ➔ OUTPUTS
1. Power Module + Switch Module
•	Power Module: Supplies electric energy from a 9V battery to all blocks.
•	Switch Module: Master safety button. Turns the entire machine ON or OFF.
2. Sensor Base & 3-Pin Connector Wire
•	Sensor Base: The input brain! It has a socket to plug in different sensors using a flexible 3-pin connector wire.
•	Obstacle (IR) Sensor: Emits invisible infrared light. When a train rolls in front, the light bounces back!
•	Knob (0 to 99): The threshold dial. Set a number (like 40). When the sensor detects a signal equal to or higher than 40, the Sensor Base fires a trigger forward!
3. Timer Module (The Digital Stopwatch)
•	Pulse Mode: Once triggered, it holds power ON for your chosen time (e.g., 5 seconds), even if the sensor stops seeing the train!
•	Delay Mode: Waits for the set time before passing power.
4. Copy Block (The Signal Splitter)
•	Takes one input signal and duplicates it into two identical outputs at the exact same instant!
5. Outputs: Servo Motor & Buzzer
•	Servo Motor Base + Servo: Turns from 
0∘0∘
 (Gate Down) to 
90∘90∘
 (Gate Up).
•	Buzzer / Red LED Module: Sounds a loud alert and flashes bright red for road safety.

3: THE GREAT LOGIC PUZZLE
Nova: "Hold on, Engineers! Where should the Copy Block go?"
We want the Gate closed for 5 seconds AND the Buzzer beeping for 5 seconds.
codeCode
IDEA A: COPY BEFORE TIMER
[Sensor Base] ➔ [Copy Block] ┬➔ [Timer] ➔ [Servo Motor] (Closes for 5s)
                             └➔ [Buzzer] (Beeps for only 1s!) ❌

IDEA B: COPY AFTER TIMER
[Sensor Base] ➔ [Timer (5s Pulse)] ➔ [Copy Block] ┬➔ [Servo Motor] (Closed for 5s)
                                                  └➔ [Buzzer] (Beeps for 5s!)   ✅
•	If we pick Idea A: The sensor only sees the train engine for 1 second as it zooms past. The buzzer rings for only 1 second and then goes dead silent, while the gate stays down for 5 seconds! Drivers will get confused.
•	If we pick Idea B: The sensor triggers the Timer. The Timer holds a steady 5-second pulse. The Copy Block splits that 5-second pulse so the Gate stays down AND the Buzzer rings together for all 5 seconds!
Nova's Verdict: "Idea B is a true Fail-Safe Design! Let's build it!"

🎛️ The 2-Step Calibration Lab
Step 1: Tune the Sensor Base Knob (0 to 99)
1.	Turn the Switch ON.
2.	Roll your toy train on the tracks right in front of the Obstacle Sensor.
3.	Turn the knob on the Sensor Base until its red indicator LED lights up.
4.	Move the train away. The indicator light should turn OFF.
5.	A setting around 40 to 50 is ideal—it spots the train body but ignores room shadows!
Step 2: Set the Timer Module
1.	Flip the small switch to PULSE.
2.	Turn the dial to 5 Seconds (giving the toy train time to cross fully).
⚡ NOVA’S BRAIN TRICK:
"What if an engineer sets the Timer to DELAY instead of PULSE?"
The gate will do nothing while the train passes, wait 5 seconds, and then close after the train has already left!
Rule: Pulse acts immediately and holds; Delay waits before acting!
