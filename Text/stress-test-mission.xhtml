12-STEP HARDWARE ASSEMBLY PROCEDURE

  1. Disconnect USB-C power supply from the UltraBoard V2 main board before making any wiring connections.
  2. Mount the UltraBoard V2 firmly onto the anti-static workspace workbench surface using 4 M3 nylon standoffs.
  3. Connect the 4-pin JST harness from the 128x64 OLED Display to I2C Port 1 (VCC -> 3.3V, GND -> GND, SDA -> D21, SCL -> D22).
  4. Plug the DHT22 Temperature & Humidity Sensor cable firmly into Sensor Port 1. Verify VCC aligns with 3.3V red wire.
  5. Connect the Analog Capacitive Soil Moisture Sensor cable into Input Port 2 (Signal Pin GPIO34).
  6. Attach the 5V Submersible Water Pump power lead connectors into Motor Port 1 (OUT+ and OUT- terminals).
  7. Connect the 40mm PWM Exhaust Cooling Fan signal line to Servo Port 2 (Control Signal Pin GPIO15).
  8. Inspect all wiring terminals under adequate lighting to ensure zero cross-bridging or loose jumper strands.
  9. Connect the 5.0V 2.5A USB-C Power Adapter to the main power terminal on UltraBoard V2.
  10. Observe the Green Power Indicator LED (PWR) — verify steady solid green light within 500ms of boot.
  11. Verify OLED display splash text: "UltraMinds OS v3.0 - Booting Climate Engine...".
  12. Measure current draw with inline USB multimeter — confirm baseline idle current is below 85mA.

MICROPYTHON CONTROL LOOP CODE

import machine
import time
import dht

# Pin Initialization
dht_sensor = dht.DHT22(machine.Pin(4))
i2c = machine.I2C(0, scl=machine.Pin(22), sda=machine.Pin(21))
pump = machine.Pin(12, machine.Pin.OUT)
fan_pwm = machine.PWM(machine.Pin(15), freq=1000)

TEMP_SETPOINT_MAX = 24.0
HUMI_SETPOINT_MIN = 55.0

def read_climate_matrix():
    dht_sensor.measure()
    t = dht_sensor.temperature()
    h = dht_sensor.humidity()
    return t, h

def execute_feedback_control(t, h):
    if t > TEMP_SETPOINT_MAX:
        fan_pwm.duty(800) # Activate exhaust fan
    else:
        fan_pwm.duty(0)
        
    if h < HUMI_SETPOINT_MIN:
        pump.value(1) # Pulse water pump
    else:
        pump.value(0)

while True:
    temp, humi = read_climate_matrix()
    execute_feedback_control(temp, humi)
    time.sleep(2.0)

PHYSICAL & MATHEMATICAL EQUATIONS

Relative Humidity Calculation Formula:

RH_percent = (e / e_sat) * 100

Where vapor pressure e_sat(T) = 6.11 * 10^( (7.5 * T) / (237.3 + T) ) in hPa.

PWM Duty Cycle Percentage Calculation:

Duty_Percent = (Raw_PWM_Value / 1023.0) * 100

LAB SAFETY & ENGINEERING NOTES

CRITICAL SAFETY WARNING: Never submerge the main electronic circuit board or wiring connectors in water. Only the sealed IP68 pump motor head and waterproof probe tip may contact water.

ENGINEERING BEST PRACTICE: Always double-check wire polarities before applying 5V DC power. Reversing VCC and GND on the DHT22 sensor will cause thermal breakdown within 3 seconds.

MISSION ASSESSMENT & KNOWLEDGE CHECK

Question 01: What is the operating voltage requirement for the DHT22 sensor when connected to Sensor Port 1?

Answer 01: The DHT22 operating voltage is strictly 3.3V DC.

Question 02: Which communication protocol is utilized by the SSD1306 128x64 OLED display?

Answer 02: Inter-Integrated Circuit (I2C) protocol utilizing SDA (Data) and SCL (Clock) lines.

Question 03: Why is non-blocking asynchronous timing preferred over time.sleep() in continuous control loops?

Answer 03: Non-blocking loops allow the microcontroller to read sensors and process emergency stops continuously without freezing execution.

Question 04: What happens if ambient temperature exceeds 24.0°C in the MicroPython feedback controller?

Answer 04: The controller activates the PWM exhaust cooling fan at 800 duty (~78% speed) on Servo Port 2.
