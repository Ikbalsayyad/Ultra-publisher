Smart Climate Monitor

Let's build a Smart Climate Monitor using DHT11 and OLED!

MISSION STORY

Commander Nova has received a request from the UltraCity Environment Center.

Classrooms, laboratories and homes are getting too hot some days and too cold on others.

To maintain comfort and save energy, engineers need real-time temperature and humidity data.

Your mission is to build a Smart Climate Monitor using the DHT11 sensor and OLED display with the UltraCore board.

REAL WORLD

This data is used in:

  • Smart Classrooms

Engineers use sensors to make the environment better for everyone.

CURIOSITY BOX

Humidity affects how we feel, helps plants grow and protects electronic devices. Too much or too little can create problems!

BUILD LAB: Hardware Setup

Let's assemble the hardware before we write the logic.

1 Connect DHT11

Connect the DHT11 sensor to the digital port.

VCC 3.3V
DATA DHT11 (Signal)
GND GND
2 Connect OLED

Connect the OLED display using the I2C port.

VCC 3.3V
GND GND
SDA I2C SDA (D21)
SCL I2C SCL (D22)

FLOW OF LOGIC

Start
Read Temperature from DHT11
Read Humidity from DHT11
Store in Variables (temp, humi)
Display both values on OLED
Wait 2 Seconds
Repeat Forever
PYTHON LOGIC PREVIEW main.py 
import dht
import time
from machine import Pin, I2C
from ssd1306 import SSD1306_I2C

# Initialize Sensor
d = dht.DHT11(Pin(4))

while True:
    d.measure()
    t = d.temperature()
    h = d.humidity()
    print("Temp:", t, "Humidity:", h)
    time.sleep(2)

The DHT11 has two sensing parts inside: A thermistor and a capacitive humidity sensor.
