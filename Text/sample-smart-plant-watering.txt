💻 The Block Code Blueprint:
codeText
when program starts
forever
    if <(read Soil Moisture on Port P1) < 30> then
        set Status LED on P2 to [ON]
        set Water Pump on M1 to [100]%
        wait (3) seconds
        set Water Pump on M1 to [0]%
        set Status LED on P2 to [OFF]
        wait (5) seconds
    else
        set Water Pump on M1 to [0]%
        set Status LED on P2 to [OFF]
________________________________________
🎛️ Nova’s 2-Step Coding Walkthrough:
1.	The Condition Block (< 30):
From the Logic menu, grab the green < (less than) block. If moisture drops below 30%, Ferny is thirsty!
2.	The Controlled Sip (wait 3 secs):
Turn Motor M1 on to 100%, wait 3 seconds to deliver a gentle drink, and then immediately set Motor M1 back to 0%!
3.	The Else Safe-State:
If moisture is 30% or higher, the code jumps straight to else and keeps the pump turned OFF!
⚡ Nova’s Brain Trick:
"Think of the if-then-else block like a railway track switch! If the condition is TRUE (soil < 30%), the train takes Track 1 (Pump). If FALSE, it takes Track 2 (Sleep)!"
